# ระบบเกียรติบัตรและประกาศผล — การประกวดวาดภาพระดับเยาวชน 2569

หน้าเว็บของระบบ (GitHub Pages) ข้อมูลทั้งหมดอยู่ใน Google ของผู้ดูแล repo นี้มีเฉพาะโค้ดหน้าเว็บและเทมเพลตภาพประกาศผล

- `admin.html` — หน้าแอดมิน (ต้องมีคีย์)

ห้ามใส่ข้อมูลนักเรียน คีย์ ฟอนต์เชิงพาณิชย์ หรือไฟล์ PDF เกียรติบัตรลงใน repo นี้

สงวนลิขสิทธิ์ โลโก้และเทมเพลตเป็นของหลักสูตรศิลปะและการออกแบบ คณะมนุษยศาสตร์และสังคมศาสตร์ มหาวิทยาลัยราชภัฏเชียงใหม่
